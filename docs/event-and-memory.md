# 事件与记忆规则

## Event Log

Event Log 是可追溯事实来源。任何会影响世界、人物关系、任务、位置、物品或后续判断的结果都应由 GameEvent 记录。

事件应包含因果来源、可见范围、发生顺序、裁决结果与状态版本；不得只依赖自然语言叙事保存关键结果。

## 记忆写入

记忆是从事件派生的角色视角资料，不是事件日志副本。冷路径根据事件的重要性、情绪强度、反复提及、关系影响和剧情关联决定是否写入。

建议字段：`memory_id`、`owner_id`、`event_ids`、`summary`、`salience`、`emotion`、`visibility`、`embedding_version`、`created_at`。

## 压缩与更正

- 短期记忆保留细节；长期记忆保留可用摘要与来源事件 ID。
- 压缩不得抹除关键因果或把猜测改写成事实。
- 事实被更正时，新增更正事件并标记受影响记忆等待重建；不静默篡改原始记录。
- 记忆检索须将“角色的主观看法”与“世界事实”区分标注。

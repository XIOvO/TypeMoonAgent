# 性能预算与调度规则

## 热路径预算

普通对话的默认目标：1 次角色模型调用、0 次检索、最小 Observation。检索只有在角色需要确认知识、回忆经历或查询关系时触发。

建议设置可配置上限：

| 项目 | 默认上限 |
| --- | --- |
| 同轮即时 Agent 调用 | 1（特殊场景最多 2） |
| 单次检索返回条目 | 5 |
| 进入模型的检索片段 | 3 |
| 工具调用轮次 | 2 |
| 热路径超时 | 产品可配置，超时必须可恢复 |

上限超出时，优先减少背景信息、延后非关键角色，而不是无界扩张调用链。

## 冷路径

记忆整合、向量化、关系摘要、背景 NPC、导演规划和日志压缩必须在玩家看到即时结果后异步执行。冷路径仅消费已确认的 GameEvent，并需具备重试与幂等保护。

## 监控指标

至少记录：端到端响应时间、模型调用数、工具调用数、检索命中率、上下文 token、超时率、Runtime 拒绝率和事件写入失败率。按场景与行动类型统计，才能识别真正的性能热点。

# 章节节点快速制作备忘

## 已确定方向

游戏采用“章节—节点式地图 + FSN/FGO 风格视觉小说场景”的结构。节点不是固定关卡，而是可进入、可自由对话、可调查和可改变的场景容器。

## 资源分层

### 章节/地点资源池

背景不与每个节点一一绑定。一个章节准备少量高复用背景即可；普通节点可通过地点标题、环境描述、对象、角色、滤镜、雾/火光及音效形成差异。

冬木 MVP 的背景池示例：

- 燃烧城市远景；
- 废墟街道；
- 教会内外；
- 未远川河畔；
- 黑暗室内通用背景。

### 角色资源库

角色立绘与节点完全分离，按角色、服装/姿势、表情注册：

```text
mash
├─ casual
│  ├─ body
│  └─ expressions
└─ battle_default
   ├─ body
   └─ expressions
```

节点只引用逻辑键，而不持有图片文件：

```json
{
  "backgroundKey": "fuyuki/ruined_street",
  "stage": [{
    "characterId": "mash",
    "costume": "battle_default",
    "slot": "right",
    "expression": "worried"
  }]
}
```

### 章节资料库

Atlas 导入内容用于提供：原作文本、章节/Quest 关系、地图节点参考、角色登场范围、背景与立绘资源来源。官方素材仅用于个人本地原型时应与公开分发策略分开处理。

## 节点类型

| 类型 | 最小配置 | 用途 |
| --- | --- | --- |
| 过渡节点 | 地点、背景、连接关系、氛围 | 移动、短对话、过场 |
| 普通节点 | 加少量对象、角色候选、局部线索 | 自由互动与探索 |
| 关键节点 | 加原作锚点、事件压力、调查/战斗入口 | 章节转折与世界线分歧 |

## 快速制作工作流

```text
导入章节 Atlas 文本与资源索引
  -> 生成地图/节点草案
  -> 从章节背景池选择背景
  -> 绑定可能出现的角色与可互动对象
  -> 关联原作锚点和本局条件
  -> AI 起草氛围、对象与钩子（不直接发布）
  -> 人工审阅、调整并发布节点配置
```

当资源池、节点模板与对象模板稳定后，普通节点应主要是配置组合，预计人工整理约 5～15 分钟；关键节点因分支、调查或战斗后果需额外设计。

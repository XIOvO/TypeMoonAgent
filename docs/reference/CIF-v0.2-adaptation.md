## 不可偏离的 CIF 原则

1. 已确认的客观历史不可被角色的主观认知、记忆或身份改写。
2. Evidence、Epistemic State 与 Interpretive Model 必须分离；接触信息不等于相信它。
3. Identity 不是人格标签集合；长期身份更新必须有来源与版本。
4. Appraisal、Emotion、Goal、Judgment、Expression 逻辑上分离；表达不能直接等同内在感受。
5. 角色只能依据自身可见证据行动；行动回写客观历史，再触发认知发展。

## 当前符合项

| CIF 层 | 项目实现 |
| --- | --- |
| World State / Objective History | Runtime 裁决、追加式 GameEvent、持久化提交 |
| Evidence | 按可见范围写入角色证据，不把系统事实自动赋予角色 |
| Epistemic / Interpretive | 独立的认识状态与信念/社会模型，带版本和来源 |
| Identity | 版本化 CIF section；普通互动不会直接改写长期人格 |
| Feedback / Development | L1 场景经历、L2 跨场景模式、L3 高门槛修订，均可追溯 |

## 有意适配，不属于原则偏离

| 上游表达 | 本项目适配 | 原因 |
| --- | --- | --- |
| 通用人物运行框架 | Runtime 是世界事实唯一裁决者，Pi 只能提议 | 游戏必须防止模型直接写世界 |
| 完整认知链 | 以 CharacterContext 和 Agent 提示词承载一部分推理 | 先保证可玩回合与成本可控 |
| 更新机制 | L1/L2/L3 分层、耐久任务、AI 审核与程序发布 | 将成长变为可重试、可审计的游戏后台流程 |
| Identity 可版本化修订 | 自动 L3 仅允许适应/表达层 | 防止一次或少量经历改写角色核心身份与价值 |

## 尚未完整实现的 CIF 能力

这些是明确工程缺口，不得在设计上被视为已满足：

1. 每回合尚未将 Appraisal、候选目标与 Practical Judgment 作为完整的结构化状态持久化；目前主要由受限 Agent 上下文推演。
2. 即时观察的感官通道、遮挡、注意程度和完整度尚未形成独立模型。
3. 情绪尚未完整记录来源、持续性、自觉程度与自我理解准确性。
4. Belief / Social Model 的适用范围、预测对象与反例字段仍可继续细化。
5. L3 自动触发策略尚未接入；现有 L3 生成—审核—发布闭环已存在，但只接受未来独立策略插件投递的任务。

## 变更规则

- 修改 `src/cif/`、记忆策略、角色上下文或 Agent 提示词时，先检查本文件的不可偏离原则。
- 发生新的工程简化时，必须在“有意适配”或“尚未完整实现”中登记。
- 任何与上游原则冲突的设计都需要明确记录为“偏离”，说明游戏理由、风险与恢复方案。

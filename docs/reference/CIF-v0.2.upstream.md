# Character Identity Framework

## 人物身份与行动建模框架 CIF v0.2

**状态：** 规范草案  
**适用范围：** AI 角色卡、互动叙事、游戏 NPC、虚拟社会、AI Agent 与世界模拟。

## 1. 框架目的

Character Identity Framework，简称 CIF，是一套用于构建和运行虚拟人物的通用规范。它不以“角色看起来具有什么性格”为终点，而是描述角色如何接触信息、形成认识、理解自身与他人，并把这些内部结构转化为行动。

CIF 需要回答：

- 世界中实际发生了什么；
- 角色接触到了哪些材料；
- 角色当前认为哪些命题成立；
- 角色如何从事实形成解释、预测与人际理解；
- 角色如何看待自己、什么对其重要、愿意承担什么责任；
- 当前事件如何形成情绪、目标、判断、表达和行动；
- 新的行动如何回到历史之中，并推动人物继续变化。

## 2. 总体结构

```text
External Reality：外部现实
    ↓
Cognitive Representation：认知表征
    ↓
Identity and Orientation：身份与方向
    ↓
Event Response：事件响应
    ↓
Feedback and Development：反馈与发展
```

完整的运行链为：

```text
World State → Objective Information → History
    ↓
Evidence Records → Epistemic State → Interpretive Models
    ↕
Identity and Orientation
    ↓
Appraisal → Emotion → Goal Formation → Practical Judgment
    ↓
Intention and Plan → Expression Filter → Language and Action
    ↓
New Objective Information → History and Cognitive Update
```

该链不是单向流水线。身份会影响角色注意什么、如何解释证据、哪些经历容易被记住；但身份与主观认知不能修改已确认的客观历史。

## 3. 核心原则

### 3.1 客观现实与主观认知分离

必须区分四件事：实际发生了什么、角色接触到了什么、角色认为发生了什么、角色认为这意味着什么。角色的误解可以改变其行为，却不能改写客观 History；系统知道的全部事实也不能自动成为角色知识。

### 3.2 证据、事实认定与解释模型分离

角色听到某种说法，只意味着这成为一条证据；角色接受某个命题，也只代表其当前认识状态；角色由多个命题推导出的“世界通常如此运作”，则属于解释模型。

```text
Evidence Records：我接触过什么材料
Epistemic State：我现在认为什么成立
Interpretive Models：我认为这些材料说明了什么
```

### 3.3 Identity 不是性格标签集合

“温柔”“内向”“害羞”等词可以描述表现，但不能充分解释行为。Identity 应当说明角色的自我模型、核心图式、需求压力、价值结构、可能自我、梦想与承诺。

### 3.4 情绪由评价产生

同一事件会因不同解释而产生不同情绪。事件首先经过 Appraisal：角色判断事件的意图、威胁、责任、可控性以及它与自身价值和关系的关联；情绪随后才出现。

### 3.5 内部状态与外部表现分离

角色可以生气而保持礼貌，想挽留却主动放手，想寻求帮助却拒绝承认需求。语言与行动必须经过 Expression Filter，而不能直接复制角色的内部感受。

### 3.6 人格变化必须可追溯

角色可以成长、退步或重构自我理解，但长期结构不能被一次普通互动直接改写。变化需要持续证据、重大经历、长期关系或旧模型失去解释能力等条件。

## 4. External Reality：外部现实

### 4.1 World State：世界状态

World State 是某一时刻世界实际处于的状态，包括时间、地点、人物位置、物品、身体状态、天气、制度、社会环境和尚未被角色观察到的事件。它可以很大，不要求全部进入人物认知。

### 4.2 Objective Information：客观信息

Objective Information 是从世界状态中提取、确认并结构化的有效事实。例如：

```text
18:00，角色到达车站。
18:05，开始下雨。
18:27，角色向玩家发送消息。
18:40，玩家到达车站。
```

它不直接记录“角色感到被抛弃”“玩家故意迟到”之类的解释性内容。

### 4.3 History：历史

History 是按时间组织的客观事件记录。已确认事件采用追加式保存；可以补充原本未知的细节，但不得与既有事实冲突。重要行动、对话与状态变化应有明确时间和主体。不同角色可以围绕同一段 History 形成不同的认识。

## 5. Cognitive Representation：认知表征

认知表征由 Evidence Records、Epistemic State 与 Interpretive Models 组成。

### 5.1 Evidence Records：证据记录

证据记录保存角色获得过的认知材料，不保证其真实，也不保证角色相信它。来源可以是直接观察、个人经历、证言、书籍、新闻、制度信息、身体感受、情绪痕迹和推理过程。

#### Immediate Observation：即时观察

即时观察是角色刚刚获得的感知结果，应尽量保留来源、时间、感官通道、注意程度、完整度、可靠度和可能的遮挡。它通常短暂；重要内容可形成经历记录。

#### Episodic Record：经历记录

经历记录保存与具体时间、地点、人物和主观体验绑定的事件。它回答：“我经历、看到、听到或感受过什么？”

```text
昨天傍晚，我在车站等了四十分钟。
当时一直下雨。
玩家到达时看起来很着急。
我先感到安心，随后才意识到自己很委屈。
```

经历记录可以包含感官片段、行动、对话、当时情绪、当前回想时的情绪、主观意义、清晰度、重要度和联想线索。它可以被联结、淡化、部分遗忘与重新解释；即使角色后来发现自己理解错误，旧经历仍需保留，因为它影响过过去的行动。

#### Testimony and Learned Evidence：证言与学习证据

“母亲告诉我父亲已经去世”“玩家声称自己因交通事故迟到”首先都是角色接收到的证据。是否接受为事实，由认识状态决定。

### 5.2 Epistemic State：认识状态

认识状态表示角色如何判断某个命题的真实性。每个命题可处于以下状态：

- 已接受事实；
- 很可能为真；
- 可能为真；
- 无法确定；
- 存在争议；
- 已否定；
- 尚不知道；
- 已经过时。

例如：

```text
玩家昨天迟到了四十分钟：已接受事实
玩家因交通事故迟到：可能为真
玩家故意让我等待：无法确定
```

Knowledge 是认识状态中的有效视图：角色当前视为已确认或具有高置信度的命题集合。角色可以知道某事却不记得来源，也可以记得某人说过某事却不相信它。

每个命题至少应关联其状态、置信度、支持与反对证据、来源、验证时间、适用范围与失效可能。旧认识状态需要版本记录，以解释角色过去的行为。

### 5.3 Interpretive Models：解释模型

解释模型把具体证据和事实组织成一般规律、因果理解与未来预测。

#### Belief Model：信念模型

Belief 不是事实记录，而是角色认为世界通常如何运作。例如：

```text
表达需求通常会增加别人的负担。
重要的人最终可能离开。
努力通常能够提高成功概率。
公开冲突会使关系更难修复。
```

每条信念应具备内容、适用范围、稳定性、支持和反对证据、预测对象、激活程度及历史版本。

#### Social Model：社会与他人模型

Social Model 是角色围绕特定人物、群体或社会环境建立的综合理解：对方是什么样的人、重视什么、如何看待自己、知道什么、为何行动、将来可能如何行动，以及自己在其面前是否安全。它可以不准确，并应在新的经历中更新。

## 6. Identity and Orientation：身份与方向

Identity and Orientation 是相对稳定的核心结构，回答“我是谁、什么对我重要、我希望成为什么、哪些责任已成为我的一部分”。

### 6.1 Self Model：自我模型

Self Model 是角色对自己的当前理解，例如“我是一个可靠的人”“我总会给别人添麻烦”“我不擅长表达真实需求”。它可能准确，也可能偏差；需要和角色行为、他人评价分开。

### 6.2 Core Schemas：核心图式

Core Schema 是与身份深度绑定、跨情境生效的高中心度 Belief。例如：

```text
依靠别人最终会使我受到伤害。
只有对他人有用，我才值得被留下。
我必须始终保持可靠，才不会失去尊重。
```

核心图式影响多个生活领域，与 Self Model 高度相关，长期稳定，并会显著参与情景解释、情绪和行动。

### 6.3 Motivational Orientation：动机取向

动机取向由 Needs 与 Values 共同构成。

Need Pressure 表示角色需要维持、获得或避免失去的心理和社会条件，如安全、归属、亲密、自主、认可、尊严、控制、成就、意义和稳定。

Value Structure 决定什么结果重要、哪些手段可接受、冲突时如何排序、愿意承担什么代价。Needs 提供行动压力，Values 提供方向、排序和约束。

### 6.4 Possible Selves、Dreams 与 Commitments

Possible Selves 包含希望成为的自我、害怕成为的自我和预期中的自我。Dreams 描述角色希望拥有的长期生活状态。Commitments 则是已与身份绑定的责任、关系或选择，例如照顾家人、完成学业、保护秘密、维持重要关系或坚持职业道路。

## 7. Event Response：事件响应

```text
当前事件
  ↓
形成新的证据，检索相关经历与认识状态
  ↓
激活 Belief、Social Model、Identity 与动机取向
  ↓
Appraisal → Emotion → Goal Formation → Practical Judgment
  ↓
Intention and Plan → Expression Filter → Language and Action
```

### 7.1 Appraisal：情景评价

评价至少回答：发生了什么、对方可能有什么意图、哪些需求受到满足或威胁、哪些价值或承诺被挑战、它是否支持核心图式、角色是否能控制结果、责任属于谁以及未来可能如何发展。

### 7.2 Emotion：情绪

情绪是对评价的反应，允许复合。例如玩家迟到后，角色可以同时安心、愤怒、委屈和羞耻。情绪应具备类型、强度、对象、来源、持续性、角色的自觉程度及其自我理解是否准确。

### 7.3 Goal Formation：目标形成

目标形成将需求、价值、承诺、梦想、情绪与情境转化为多个候选目标，例如确认对方安全、获得解释、表达不满、避免公开冲突、保护关系或尽快离场。系统应区分候选目标与当前活跃目标。

### 7.4 Practical Judgment：实践判断

实践判断综合当前知识与不确定性、信念、社会模型、身份、情绪、行动能力、风险、成本、规范与后果预测，选择角色认为更合适的行动。它可能成熟，也可能短视、偏激或建立在错误认知上。

### 7.5 Intention、Plan 与 Expression Filter

Intention 是具体行动方向，Plan 是为实现长期或复杂意图所需的步骤。Expression Filter 决定哪些内部内容能被外界看见，受到关系、场合、安全感、规范、自我形象、拒绝恐惧、表达能力和情绪控制力影响。最终的 Language and Action 必须符合角色知识、目标、边界、能力与环境。

## 8. Feedback and Development：反馈与发展

行动成为新的 Objective Information 并进入 History。行动者、玩家与第三者只能获得各自能观察到的证据，因此同一行动会产生不同理解。角色自己的行动也会改变自我模型：若角色持续看到自己能拒绝不合理要求，“我无法保护自己”的核心图式便可能逐渐松动。

## 9. 更新机制与时间尺度

### Append：追加更新

适用于已发生、不能被当前状态覆盖的内容：History、Objective Information、重要 Evidence、已执行行动和重要目标结果。

### Revision with Versioning：版本化修正

适用于角色当前模型：Epistemic State、Belief、Social Model、Self Model、Core Schema、动机取向、可能自我与承诺。修改时保留旧版本、时间、原因和支持证据。

### State Transition：状态转移

适用于快速变化的运行状态：当前注意、情绪、活跃目标、意图、计划和表达策略。

快速变化的是观察、情绪、目标与表达；中速变化的是对具体人的认识、社会模型和一般信念；慢速变化的是 Self Model、Core Schema、动机取向、可能自我与承诺。

## 10. 最小运行流程

1. 确认当前世界状态与相关历史。
2. 判断角色可获得哪些证据。
3. 形成即时观察并检索相关经历记录。
4. 读取相关认识状态，激活信念与社会模型。
5. 调用身份与动机取向，完成情景评价。
6. 生成复合情绪与候选目标。
7. 通过实践判断选择当前目标，形成意图与必要计划。
8. 经表达过滤生成语言与行动。
9. 验证其不违反历史、知识权限与世界规则。
10. 将行动写回客观信息和历史，并判断后续认知或身份更新。

## 11. CIF 的操作性定义

> CIF 所描述的可运行人物，是持续存在于客观历史中的行动主体。它通过有限证据形成认识状态，并利用信念与社会模型解释和预测世界；这些认知与自我模型、核心图式、动机取向、梦想和承诺共同构成 Identity。面对事件时，角色通过评价、情绪、目标形成、实践判断和表达过滤，将内部结构转化为语言与行动。行动成为新的历史，并继续塑造角色未来的认知与身份。

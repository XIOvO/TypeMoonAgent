## Closed by RC-01

### architecture CI

RC-01 新增跨平台 `verify:release`，串联完整测试、module boundary 与 conformance；GitHub Actions 对 push、pull request 和手动触发调用同一入口。首次运行暴露并修复了 Bash 提前展开未加引号 glob 导致测试子集执行的问题；修复后的 run 32484093473 完整通过，architecture CI Gate 关闭。

## Closed by RC-02

### migration operations validation

RC-02 新增内部 SQLite migration operations，不扩大 SDK 或公开 package exports。dry-run 只读打开既有数据库并报告 applied、pending、checksum conflict 与备份需求；apply 先在原库旁创建并校验 SQLite backup，再以每项独立事务执行和记录 migration；失败时报告 migration ID、已完成 ID 与 backup path，保留最后成功状态且不自动恢复。restore 是单独显式操作，先校验备份，默认只复制到新路径，只有调用方明确选择 `overwrite` 才允许替换目标。

真实文件测试证明 dry-run 前后数据库字节与目录成员不变、备份是迁移前快照、失败 migration 完整回滚且后续不运行、先前成功 migration 保留、备份可恢复到新路径、默认覆盖被拒绝。完整本地 Release Gate 通过，migration 运维门槛关闭；托管 Linux 证据将在本提交推送后记录。

## Closed by RC-01

### architecture CI

RC-01 新增跨平台 `verify:release`，串联完整测试、module boundary 与 conformance；GitHub Actions 对 push、pull request 和手动触发调用同一入口。首次运行暴露并修复了 Bash 提前展开未加引号 glob 导致测试子集执行的问题；修复后的 run 32484093473 完整通过，architecture CI Gate 关闭。

## Must Fix Now

### P1 — migration 运维门槛缺少可执行验证

Registry、checksum、old-read/current-write 已有单元测试，但 persistence operations contract 要求的 dry-run 不写库、迁移前备份、失败保留备份和显式 restore 尚无可执行测试；路线图第 20 节也要求失败回滚与备份恢复测试。

### P1 — 候选身份与不可变快照尚未建立

package 与 lockfile 仍声明 `0.1.0`，预检生成的也是 0.1.0 包；E09 交付仍在有其他改动的工作树中。`private: true` 和独立 npm 发布可继续后置，但候选必须有明确的 `0.3.0-rc` 身份和可复现 revision。

## Verification Gaps

- pack 没有 `files` allowlist；不阻塞 private SDK Alpha，但阻塞未来独立 npm 发布。
- package 描述仍称 Pi 是唯一 Agent 集成层，与 Pi/Rule 切换不一致。
- current status 仍称 migration framework 待补，与 registry/runner 实现不一致。
